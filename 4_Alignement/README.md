## Point éditorial : le *reward hacking*

Le plan de présentation réserve une note orale à ce sujet dans la [diapo 8](<../Présentation/nouveau_plan_8_diapos_coherent.md>). L’exemple montre l’écart possible entre l’objectif visé et le signal de récompense mesuré : un agent peut optimiser ce signal imparfait sans réaliser la finalité qu’il devait représenter. « Tricher » ou *game-playing* sert ici d’image pédagogique ; ne pas attribuer à l’agent une intention humaine de tromper.

Pour définir le phénomène, voir Skalse et al., [*Defining and Characterizing Reward Hacking*](https://arxiv.org/abs/2209.13085) ; pour des exemples de contournement de spécification, voir [Google DeepMind](https://deepmind.google/blog/specification-gaming-the-flip-side-of-ai-ingenuity/). La référence à *Cooperative Inverse Reinforcement Learning* dans la note de fond n’étaye pas, à elle seule, une affirmation générale sur le *reward hacking* ; voir [la vérification des sources](../VERIFICATION_SOURCES_SERIE_LLM.md).
